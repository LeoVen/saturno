# Saturno

School timetable generator. See `specs/PRD.md` (with `FR.md`, `TR.md`,
`IMPL.md`, `GL.md`) for the full v1 design.

- **`specs/` is frozen.** Never edit it. It's the v1 thinking record, not a
  living doc.
- **All implementation work — planning, tasks, decisions, and eventually
  code — happens outside `specs/`.** Before doing any implementation work,
  read `impls/PROCESS.md` — it defines the epic/task workflow, status
  values, and how to record a deviation from the frozen spec (in
  `impls/DECISIONS.md`, not by editing `specs/`).
- Check `impls/BOARD.md` for current epic status before starting work.
